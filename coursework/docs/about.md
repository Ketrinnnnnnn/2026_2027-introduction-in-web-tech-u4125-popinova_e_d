# О клубе

##  Описание
Конно-спортивный клуб **«Аллюр»** был основан в **2015 году** в городе **Ангарск**.
Название «Аллюр» происходит от французского *allure* — «походка, ход лошади».

За годы работы клуб стал одним из самых популярных мест для любителей
верховой езды в Иркутской области.
