Цель работы

Научиться работать с Docker: устанавливать Docker, создавать Dockerfile, собирать образы, запускать контейнеры и управлять ими.



Ход выполнения работы

1\. Установка Docker (см скриншот Версия Docker)

2\. Запуск тестового контейнера

3\. Изучение базовых команд Docker

4\. Работа с готовыми образами (см скриншот Версия curl)

5\. Запуск веб-сервера nginx

6\. Работа с томами (volumes) (см скриншот Данные в томе)

\*7. Создание Dockerfile с Flask-приложением (см скриншот Файлы проекта в папке flask-app, Работа Flask-приложения в браузере)
