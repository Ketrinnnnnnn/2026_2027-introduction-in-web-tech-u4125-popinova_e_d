## 🚀 Правила участия

### 1. Ветки (Branches)

- **`main`** — основная стабильная ветка
- **`develop`** — основная ветка для разработки
- **`feature/название-фичи`** — отдельные ветки для новых функций (создаются от `develop`)
- **`bugfix/название-бага`** — ветки для исправления ошибок

### 2. Коммиты (Commits)

- Каждый коммит должен иметь осмысленное сообщение на **русском** или **английском** языке
